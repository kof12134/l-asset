1. **报废保留自定义字段** — `scrapped_assets` 新增 `custom_values` JSON 列，报废时保存、恢复时还原
2. **批量领用校验** — 批量 checkout 前检查所有资产是否为"在库"
3. **XML/ZIP 导出不再泄露密码** — 用户导出不再包含 password 字段
4. **导入保留 field_options** — ZIP 导入 custom_fields 补上 field_options 列
5. **附件清理** — 删除资产时同步删除磁盘上的附件文件
6. **错误信息不再泄露** — 全部 70+ 处 `err.Error()` 改为服务器端日志、前端返通用消息
7. **优雅退出** — 添加 SIGINT/SIGTERM 处理，关闭前清理 DB 连接
8. **数据库迁移健壮** — `addColumnIfMissing()` 先检查列是否存在再 ALTER TABLE
9. **Windows 隐藏控制台** — 编译加 `-H windowsgui`，托盘程序不再弹黑色窗口
